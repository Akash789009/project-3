# Responsive Design Tokens & Mobile-First CSS Architecture

A GitHub-ready responsive dashboard demonstrating modern CSS custom properties, CSS Grid, Flexbox, fluid breakpoints, light/dark theme variables, glassmorphism, hover transitions, and mobile-first responsive behavior.

## Assignment requirements covered

- Design-token palette in `:root`
- Brand colors, typography scale, spacing tokens and border radii
- CSS Grid + Flexbox dashboard layout
- Responsive breakpoints: 320px, 768px, 1024px and 1440px
- Light/dark theme variables
- Subtle glassmorphism/backdrop blur
- Soft shadows and hover transitions
- Mobile-first CSS
- No intentional horizontal overflow

## Run locally

This is a static project.

```bash
python -m http.server 8080
```

Open:

```text
http://localhost:8080/
```

## Responsive proof

Test at these viewport widths:

- 320px — compact mobile
- 375px — normal mobile
- 768px — tablet
- 1024px — laptop
- 1440px — desktop

Capture screenshots at each width for the GitHub submission.

## Theme

Use the **Theme** button to switch between light and dark token sets. The selected theme is also stored in `localStorage`.
